# Práctica P4 - Web boda con carrito

## Estructura
- `index.html` → página principal con timeline, mapa y countdown
- `gifts.html` → lista de regalos con scroll
- `cart.html` → carrito
- `checkout.html` → formulario de pago
- `styles.css` → estilos generales
- `script.js` → timeline, countdown y carrito con `localStorage`
- `assets/images/` → imágenes de la pareja

## Qué puedes modificar rápido
### 1. Orden de las fotos
Edita el array `timelineData` dentro de `script.js`.

### 2. Regalos y precios
Edita el array `giftItems` dentro de `script.js`.

### 3. Textos de la boda
Cambia directamente los textos de cada HTML.

### 4. Colores
En `styles.css`, cambia las variables de `:root`.

## Publicar en GitHub Pages
1. Sube la carpeta al repositorio `p4`.
2. Haz commit y push.
3. En GitHub entra en `Settings` → `Pages`.
4. En `Build and deployment`, elige `Deploy from a branch`.
5. Selecciona la rama `main` y carpeta `/root`.
6. Guarda y espera unos minutos.
7. Tu URL será parecida a: `https://TU-USUARIO.github.io/p4/`
